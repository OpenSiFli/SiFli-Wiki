# 墨水屏波形转换工具

## 1. 概述

SFW 波形工具用于将墨水屏（E-Paper / 电子纸）厂商提供的各类私有格式波形文件，统一转换为 SiFli 平台固件可直接加载的**项目标准 `.bin`**。

工具提供三种使用形态：

| 形态 | 适用场景 | 入口 |
|------|---------|------|
| **网页版**（推荐） | 免安装，浏览器直接使用，文件不上传服务器 | <a href="../_static/epd-waveform/index.html" target="_blank">打开网页版工具</a> |
| **桌面版** | Windows 本地使用，功能与网页版一致 | [下载工具包](https://downloads.sifli.com/tools/WaveformTool/WaveformTool_latest.7z) |
| **命令行** | 批量转换 / 脚本集成 | 包含在上述工具包中 |

出于厂商波形数据保密考虑，所有形态均**只输出标准 `.bin`，不导出 C 源码或波形表格**。

## 2. 支持的输入格式

| 输入格式 | 状态 | 说明 |
|---------|------|------|
| WBF 标准 PVI | ✅ 已支持 | E Ink 原始波形格式，支持 4-bit（16 灰）与 5-bit（32 灰，自动降采样） |
| WBF 私有包装 | ✅ 已支持 | 厂商在 PVI 波形流外包裹私有 header 的变体，通过指针扫描自动提取波形段 |
| 厂商 BIN | ✅ 已支持 | 厂商私有 header + 固定布局波形区，自动跳过全常量空壳模式 |
| 标准 BIN | ✅ 已支持 | 本工具链输出的项目标准格式，支持重打包、版本调整与回读验证 |
| XLSX 波形表格 | ✅ 已支持 | 按模板约定排列的波形 Excel 表，支持电压值映射与多工作表多模式 |
| RKF（Rockchip EBC） | 🚧 适配中 | 瑞芯微 EBC 控制器专用容器；内部多为 PVI 波形流，可先用「RKF·AWF 等」通用扫描尝试解析 |
| WRF（i.MX EPDC） | ❌ 暂不支持 | Freescale / NXP EPDC 加载格式，常见于 Kindle 等设备，可使用 inkwave 脚本部分处理 |
| 厂商 .h 头文件 LUT | ❌ 暂不支持 | SSD16xx / UC8xxx SPI 屏常见 C 头文件数组，属控制器寄存器 LUT，适配方案定义中 |
| IT8951 / OTP 内嵌波形 | ❌ 暂不支持 | 波形固化在固件或 OTP 中，需先从固件镜像提取 |

## 3. 快速开始

**网页版**：直接打开 <a href="../_static/epd-waveform/index.html" target="_blank">网页版工具</a>，所有解析与转换均在本地浏览器完成，任何文件不会上传；转换结果通过浏览器下载。

**桌面版**：双击 `SFW_Waveform_Tool.exe` 启动（免安装）。

基本流程：

1. 在左侧选择功能页。
2. 选择输入文件（选择后输出路径会自动按同名规则填充，可修改）。
3. 点击主按钮开始转换，进度与结果在下方**运行日志**中查看。

> 网页版除 XLSX 转换需联网加载 SheetJS 解析库外，其余格式解析完全离线可用。

## 4. 功能页详解

### 4.1 波形转换 → BIN

把 WBF 及各厂商私有波形转换为标准 `.bin`，并列出模式（mode）、帧数与温区信息。

| 参数 | 说明 |
|------|------|
| 波形文件 | 输入 `.wbf` 或 `.bin` |
| 输入格式 | **自动识别**（推荐）：按 WBF 标准 PVI → WBF 私有包装 → 通用扫描（RKF/AWF 等）顺序尝试；也可手动指定 |
| 输出 BIN | 输出路径，选择输入文件后自动填为同名 `.bin` |
| BIN 版本 | 留空使用默认值 |
| 仅解析，不输出 bin | 勾选后只查看模式 / 温区 / 帧数信息，不写文件 |
| 交换新旧灰阶 | 默认关闭；仅在画面刷新异常时启用（交换 LUT 索引的 old/new 灰阶） |

LUT 索引固定为 `index = old_gray << 4 | new_gray`。

### 4.2 BIN → BIN

把厂商私有 bin 或旧的标准 bin 重新打包为标准 bin，用于格式统一与版本调整。

| 参数 | 说明 |
|------|------|
| 输入 BIN | 厂商 bin 或标准 bin |
| 输入格式 | **自动识别**（推荐）/ 标准 BIN / 厂商 BIN |
| 输出 BIN | 输出路径，默认填为 `*_std.bin` |
| 输出版本 | 留空使用默认值 |
| 交换新旧灰阶 | 同 4.1 |

说明：

- 厂商 bin 会**自动跳过全常量（空壳）mode**（如 mode 0–4），因此输出文件通常比厂商 bin 小，属正常现象；固件加载时同样会跳过这些空模式。
- 标准 bin 原样复读输出（byte 级一致），可用于数据完整性验证。

### 4.3 XLSX → BIN

把波形表格（Excel）转换为标准 `.bin`。

| 参数 | 说明 |
|------|------|
| XLSX 文件 | 输入表格 |
| 输出 BIN | 输出路径 |
| 工作表 | 留空表示处理**全部数据表**；也可指定单个 sheet 名 |
| 值映射 | 电压 → 2-bit 映射，默认 `-15:2,0:0,15:1`（-15V→2，0V→0，+15V→1） |
| BIN 版本 | 留空则读取表内 `Config` 工作表 |

> **波形模板文件**：<a href="../_static/epd-waveform/Waveform_to_bin.xlsx" download>Waveform_to_bin.xlsx</a> —— 这是用于生成 bin 文件的标准波形模板（含 `Config` 与 GC16 / DU / GC4 / INIT / DUMMya / GL16 / A2 / DU4 等数据工作表）。在此模板基础上填入或修改波形数据，即可通过「XLSX → BIN」页（或命令行 `waveform_xlsx_to_cbin.exe`）生成标准 bin 文件。

## 5. XLSX 波形表格模板

标准模板文件 <a href="../_static/epd-waveform/Waveform_to_bin.xlsx" download>Waveform_to_bin.xlsx</a> 的结构约定如下（自定义新表格时请保持同样的行列布局）：

```
Config sheet:
  row 1: key | value | description
  row 2: version | (版本号) | Bin format version
  row 4: sheet_name | mode_index
  row 5+: GC16 | 5
          DU   | 1
          ...

数据 sheet (如 GC16):
  row 1: [temperture | Old gray scale | New Gray Level | Frame | 1 | 2 | ... | N]
  row 2..257:   tmin | 0 | 0 | fc | v1 | v2 | ... | vN   (第一个 temp_block)
  row 258..513: tmin | 0 | 1 | None | ...
  ...
```

- 每个 temp_block 256 行（old_gray 0–15 × new_gray 0–15）
- 温度与 frame_count 只在每个 block 的第一行填一次
- 电压值为 -15 / 0 / 15
- `Config` sheet 的 `sheet_name → mode_index` 映射允许自定义 sheet 名，不再受限于固定映射表

### mode 编号参考

| mode | 标准名 | 说明 |
|------|--------|------|
| 1 | DU | 快刷新 |
| 2 | GC4 | 4 灰全局更新 |
| 3 | INIT | 初始化 |
| 5 | GL16 | 16 灰 |
| 6 | A2 | A2 模式 |
| 7 | DU4 | 4 灰快刷新 |
| 8 | GLR16 | 16 灰 |
| 9 | GLD16 | 16 灰 |
| 0 | GC16 | 16 灰全局更新 |
| 10–15 | - | 厂商自定义有效波形 |

## 6. 输出 bin 的验证

1. **回读验证（零误差）**：把输出 bin 再走一次 BIN → BIN，与自身对比应完全一致。
2. **固件加载（最权威）**：烧录后启动日志出现 `Custom EPD wave table validation OK`。

## 8. 常见问题

- **输出 bin 比厂商 bin 小很多？**
  正常：厂商 bin 含 3KB 私有 header + 多个全常量空壳 mode，本工具只保留有效 mode，固件加载时也会跳过空壳 mode。
- **画面刷新灰阶错乱？**
  尝试勾选「交换新旧灰阶」重新转换。
- **大 xlsx 转换报内存错误？**
  改用 bin 直转路径（命令行 `vendor_bin_to_cbin.exe` 或 GUI 的 BIN → BIN 页）。
- **只想查看波形里有哪些模式 / 温区？**
  用「波形转换 → BIN」页勾选「仅解析，不输出 bin」。
- **拿到的是 RKF / AWF 等未列出的私有格式？**
  先用「自动识别」尝试；若失败可手动选「RKF·AWF 等」走通用扫描。完整格式适配计划见工具包内《格式调研与适配计划》。
