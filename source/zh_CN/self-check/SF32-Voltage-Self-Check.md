# SF32 硬件电压自检指南

:::{attention}
本文档用于客户完成硬件设计后，出现死机或连接不上jlink时自行检验各电源节点电压是否正常。请根据您使用的芯片系列，对照相应的电压规格进行检测。
:::

## 检测前准备

### 所需工具

- 万用表（精度±1%）
- 示波器（用于纹波检测，可选）
- 开发板或自制测试板

### 检测条件

- 供电电源稳定，纹波尽量小
- 芯片处于正常工作状态（非睡眠模式）

## SF32LB52x 系列（锂电池供电版本）

:::{note}
适用型号：SF32LB520U36、SF32LB523UB6、SF32LB525UC6、SF32LB527UD6
供电方式：锂电池供电，支持USB充电
:::

### 电源电压检测表

| 检测点                | 典型电压(V) | 允许范围(V) | 最大电流(mA) | 检测说明                               |
| --------------------- | ----------- | ----------- | ------------ | -------------------------------------- |
| **VBUS**        | 5.0         | 4.6 ~ 5.5   | 500          | USB充电输入，插入充电器时检测          |
| **VBAT**        | -           | 3.2 ~ 4.7   | 500          | 电池电压，电池供电时检测               |
| **VCC**         | -           | 3.2 ~ 4.7   | 500          | 系统主电源，锂电池供电时与VBAT相近     |
| **VSYS**        | 3.3         | -           | 500          | 射频供电输出                           |
| **BUCK_LX**     | 1.25        | -           | 50           | DC-DC输出，接电感                      |
| **BUCK_FB**     | 1.25        | -           | 50           | DC-DC反馈，接电感另一端                |
| **VDD_VOUT1**   | 1.1         | -           | 50           | 内部LDO1输出（内部电源，不给外设供电） |
| **VDD_VOUT2**   | 0.9         | -           | 20           | 内部LDO2输出（内部电源，不给外设供电） |
| **VDD_RET**     | 0.9         | -           | 1            | 内部保持LDO（内部电源，不给外设供电）  |
| **VDD_RTC**     | 1.1         | -           | 1            | RTC电源（内部电源，不给外设供电）      |
| **VDD18_VOUT**  | 1.8         | -           | 30           | SIP电源（内部电源，不给外设供电）      |
| **VDD33_VOUT1** | 3.3         | -           | 150          | 3.3V LDO输出1（需软件配置才有输出）    |
| **VDD33_VOUT2** | 3.3         | -           | 150          | 3.3V LDO输出2（需软件配置才有输出）    |
| **AVDD33_AUD**  | 3.3         | 2.97 ~ 3.63 | 50           | 音频电源输入                           |
| **AVDD_BRF**    | 3.3         | 2.97 ~ 3.63 | 100          | 射频电源输入                           |
| **MIC_BIAS**    | -           | 1.4 ~ 2.8   | -            | 麦克风电源输出                         |

### 检测要点

:::{important}

1. **VBUS检测**：插入USB充电器时，VBUS电压应在4.6V~5.5V之间
2. **电池电压**：VBAT电压应在3.2V~4.7V之间，低电量时不应低于3.2V
3. **DC-DC输出**：BUCK_LX和BUCK_FB电压应为1.25V
4. **内部LDO**：VDD_VOUT1=1.1V，VDD_VOUT2=0.9V，这两个电压异常会导致芯片无法启动
5. **3.3V输出**：VDD33_VOUT1/VOUT2需要软件配置后才有输出，默认无输出
   :::

## SF32LB52X 系列（3.3V/1.8V供电版本）

:::{note}
适用型号：SF32LB52BU36、SF32LB52DUB6、SF32LB52EUB6、SF32LB52GUC6、SF32LB52JUD6
供电方式：3.3V电源供电（52D为1.8V），不支持充电
:::

### 电源电压检测表

| 检测点               | 典型电压(V) | 允许范围(V) | 最大电流(mA) | 检测说明                               |
| -------------------- | ----------- | ----------- | ------------ | -------------------------------------- |
| **PVDD**       | 3.3         | 2.97 ~ 3.63 | 150          | 系统主电源输入                         |
| **BUCK_LX**    | 1.25        | -           | 50           | DC-DC输出，接4.7uH电感                 |
| **BUCK_FB**    | 1.25        | -           | 50           | DC-DC反馈，接电感另一端                |
| **VDD_VOUT1**  | 1.1         | -           | 50           | 内部LDO1输出（内部电源，不给外设供电） |
| **VDD_VOUT2**  | 0.9         | -           | 20           | 内部LDO2输出（内部电源，不给外设供电） |
| **VDD_RET**    | 0.9         | -           | 1            | 内部保持LDO（内部电源，不给外设供电）  |
| **VDD_RTC**    | 1.1         | -           | 1            | RTC电源（内部电源，不给外设供电）      |
| **VDDIOA**     | 1.8/3.3     | 1.71 ~ 3.63 | -            | GPIO电源输入                           |
| **AVDD33**     | 3.3         | 2.97 ~ 3.63 | 100          | 3.3V模拟电源输入                       |
| **AVDD33_AUD** | 3.3         | 2.97 ~ 3.63 | 50           | 音频电源输入                           |
| **VDD_SIP**    | 1.8/3.3     | 1.71 ~ 3.63 | 30           | SIP电源（可内部LDO或外部供电）         |
| **AVDD_BRF**   | 3.3         | 2.97 ~ 3.63 | 100          | 射频电源输入                           |
| **MIC_BIAS**   | -           | 1.4 ~ 2.8   | -            | 麦克风电源输出                         |

### 检测要点

:::{important}

1. **PVDD检测**：主电源应在2.97V~3.63V之间，推荐3.3V
2. **VDDIOA检测**：根据芯片型号不同，可能为1.8V或3.3V
   - SF32LB52BU36：1.8V或3.3V
   - SF32LB52DUB6：1.8V
   - SF32LB52E/G/J：内部LDO供电
3. **VDD_SIP检测**：根据芯片型号不同，供电要求不同
   - SF32LB52BU36：外供1.8V或3.3V
   - SF32LB52BU56：外供3.3V
   - SF32LB52DUB6：外供1.8V
   - SF32LB52E/G/J：内部LDO供电，无需外供
4. **Hibernate模式**：使用Hibernate mode时，VDD_SIP供电要关闭，否则合封存储的I/O上会有漏电风险
   :::

## 外设供电检测注意事项

### Flash 存储供电

:::{important}

| 外挂 SPI Nand Flash          | VDD33_VOUT1               | **需要**   | **PA21** | 高电平打开，低电平关闭          |

#### SF32LB52X 系列（3.3V/1.8V供电版本）

| 存储类型                                | 供电电源           | 是否需要电源开关 | 控制引脚       | 说明                   |
| --------------------------------------- | ------------------ | ---------------- | -------------- | ---------------------- |

#### SF32LB56xU 系列

- Flash 接口：MPI（SPI Nor/NAND）或 SD（SD NAND），物理管脚兼容
- Flash GPIO 供电：**VDDIO3**（PA06~PA11），独立于其他 GPIO 电压域
- VDDIO3 电压需根据外设 Flash 接口电平设定（1.8V 或 3.3V）

来源：[SF32LB56xU-硬件设计指南 - 外接存储器](/hardware/SF32LB56xU-HW-Application)

#### SF32LB56xV 系列

- Flash 接口：MPI（SPI Nor/NAND）或 SD（SD NAND），物理管脚兼容
- Flash GPIO 供电：**VDDIOA2**（PA06~PA11），独立于其他 GPIO 电压域
- 支持 eMMC，有 VCC 和 VCCQ 两种电源域

来源：[SF32LB56xV-硬件设计指南 - 外接存储器](/hardware/SF32LB56xV-HW-Application)

### Flash 供电检测要点

:::{important}

1. **VDD_SIP 电压**：合封存储电源，52X 系列范围 1.71~3.63V，56x 系列范围 1.71~1.98V
2. **PA21 控制信号**：所有启动存储器的电源开关使能脚**必须**使用 PA21 控制，高电平打开，低电平关闭
3. **Hibernate 模式**：使用 Hibernate mode 时，VDD_SIP 供电要关闭，否则合封存储的 I/O 上会有漏电风险
4. **大容量 Flash**：外接 ≥32MB SPI Nor Flash 时，必须用 PA21 控制断电，使 Flash 退出 4BYTE Mode
5. **VDDIO 电压匹配**：56xU 的 VDDIO3、56xV 的 VDDIOA2 需根据 Flash 接口电平设定
   :::

## 常见问题排查

### 电压异常排查流程

```
电压异常
├── 电压为0V
│   ├── 检查电源芯片是否工作
│   ├── 检查使能信号是否正确
│   └── 检查焊接是否虚焊
├── 电压偏低
│   ├── 检查负载是否过重
│   ├── 检查电源芯片输出能力
│   └── 检查PCB走线是否过细
├── 电压偏高
│   ├── 检查反馈电阻是否正确
│   └── 检查电源芯片是否损坏
└── 电压纹波大
    ├── 检查滤波电容是否焊接
    ├── 检查电容值是否正确
    └── 检查PCB布局是否合理
```
