☰ 支持格式说明

本工具目前支持的输入格式，以及暂不支持格式的说明
✅ 已支持
  • WBF 标准 PVI 已支持
    E Ink 原始波形格式（柔性屏排线 Flash 中的格式），支持 4-bit（16 灰）与 5-bit（32 灰，自动降采样到 4-bit）。
  • WBF 私有包装 已支持
    厂商在 PVI 波形流外包裹私有 header 的变体，工具通过指针扫描自动提取波形段。
  • 厂商 BIN 已支持
    3072 字节私有 header + 固定布局波形区（16 模式 × 17 温区 × 51 帧）。自动跳过全常量空壳模式。
  • 标准 BIN 已支持
    本工具链输出的项目标准格式，支持重打包、版本调整与完整性回读验证。
  • XLSX 波形表格 已支持
    按模板约定排列的波形 Excel 表（Config 工作表 + 数据表），支持电压值映射与多 sheet 多模式。
🚧 暂不支持
  • RKF（Rockchip EBC 平台波形）适配中
    瑞芯微 EBC 控制器专用容器格式（RESET/DU/GC16/GL16/GLR16/GLD16/A2 七模式），文件头结构已公开。 内部多为 PVI 波形流，可先用「RKF·AWF 等 / 自动识别」尝试解析。
  • WRF（i.MX EPDC 波形）暂不支持
    Freescale / NXP i.MX508 及后续 EPDC 控制器的加载格式，常见于 Kindle 等设备。 网页版暂不支持，可在桌面版使用 wrf2sdk 脚本部分处理。
  • 厂商 .h 头文件 LUT（SSD / UC 控制器）暂不支持
    Solomon Systech（SSD16xx）/ UltraChip（UC8xxx）SPI 屏常见的 C 头文件波形数组。 属控制器寄存器 LUT，无温度分区与模式索引约定，语义与 PVI 相位流不同，适配方案定义中。
  • IT8951 / OTP 内嵌波形 暂不支持
    IT8951 主控方案的波形固化在固件或 OTP 中，需先从固件镜像提取，暂不支持直接解析。

SFW 波形工具（网页版） v1.1.2
面向 SiFli / E Ink 电子纸项目的波形转换工具。所有转换最终只输出项目标准 .bin， 不导出 C 源码或波形表格，避免厂商波形数据外泄。
纯前端实现：文件解析与转换全部在本地浏览器完成，任何文件都不会上传到服务器。
